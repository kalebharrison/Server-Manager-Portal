# Contributing

1. Use the **`beta`** branch for portal work on this fork.
2. Read [docs/development.md](docs/development.md) and [docs/architecture.md](docs/architecture.md).
3. Keep backend changes inside the matching `lib/<domain>/` folder.
4. Add tests under `tests/<domain>/`.
5. Run `npm run check` before pushing.
6. Do not reintroduce Unraid packaging; this is a standard Docker repo.
